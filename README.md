# Student Management System

A simple Student Management System developed using Java and MySQL.

## Features

- Add student
- View all students
- Search student by ID
- Update student details
- Delete student

## Technologies Used

- Java
- MySQL
- JDBC
- Git
- GitHub

## Database

Database Name: `student_db`

Table Name: `students`

## How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the `student_db` database and `students` table.
4. Update the MySQL username and password in `DBConnection.java`.
5. Compile and run `Main.java`.
